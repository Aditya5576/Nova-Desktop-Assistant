🛠️ Part 1: Install Node.js

  1. Click the Download Node.js (.msi) button above.
  2. Open the downloaded node-v20.18.0-x64.msi installer.
  3. Click Next ➔ Next ➔ Install.
  4. If Windows asks for permission, click Yes, then click Finish.

📁 Part 2: Extract Nova App Files

  1. Click the Download Nova (.zip) button above.
  2. Open your computer's Downloads folder.
  3. Right-click on Nova-Desktop-Assistant-main.zip ➔ Click Extract All....
  4. Click Extract. The extracted folder will open automatically!

🚀 Part 3: 1-Click Launch!

  1. Inside the extracted Nova-Desktop-Assistant-main folder, find setup-and-run.bat.
  2. Double-click setup-and-run.bat!
🎉 Sit back for 20 seconds! The batch script will automatically download app packages, create a Nova.lnk icon on your Desktop, and launch Nova on your screen!

🔑 Part 4: Add Free Gemini AI Key (Optional)

  1. Go to Google AI Studio and sign in.
  2. Click Create API Key and copy your key.
  3. Open Nova ➔ Click ⚙️ Settings ➔ Paste your API key ➔ Click Save Settings.
